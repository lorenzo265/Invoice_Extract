# Field catalog

The canonical field names `invoice_extractor` and `invoice_forge` share. The extractor
declares them in `extraction/specs.py` and `layout/schema.py`; the generator writes one
truth entry under each name (`docs/GROUND_TRUTH_SCHEMA.md`), and the benchmark compares
name by name. A name the extractor does not know yet is reported as "not covered",
never as wrong.

Generated by `python scripts/make_field_catalog.py`. Do not edit this file by hand:
`tests/test_field_catalog_matches_extractor.py` fails when it and the specs disagree,
and the fix is to change the specs and regenerate.

## Scalar fields

`Kind` says where on an invoice the value belongs: `scalar` for the document's own
identifiers and dates, `party` for a value that describes the supplier or the customer,
`totals` for the money block at the foot of the document.

| Field | Kind | Value type | Normalised to |
|---|---|---|---|
| `invoice_number` | scalar | `str` | the text after the label's colon, stripped |
| `invoice_date` | scalar | `date` | an ISO-8601 date |
| `due_date` | scalar | `date` | an ISO-8601 date |
| `supplier_vat_id` | party | `str` | letters and digits only, upper-cased |
| `customer_vat_id` | party | `str` | letters and digits only, upper-cased |
| `currency` | scalar | `str` | letters and digits only, upper-cased |
| `vat_rate` | totals | `Decimal` | a plain decimal string, a trailing percent sign removed |
| `subtotal` | totals | `Decimal` | a plain decimal string, the layout's separators removed |
| `vat_amount` | totals | `Decimal` | a plain decimal string, the layout's separators removed |
| `total_amount` | totals | `Decimal` | a plain decimal string, the layout's separators removed |

## Line-item columns

Every row of the line-item table carries these five columns, in this order. They are
the fields of `LineItem`, so the table and the record cannot drift apart.

| Field | Kind | Value type | Normalised to |
|---|---|---|---|
| `sku` | table | `str` | the cell's text, stripped |
| `description` | table | `str` | the cell's text, stripped |
| `quantity` | table | `Decimal` | a plain decimal string, the layout's separators removed |
| `unit_price` | table | `Decimal` | a plain decimal string, the layout's separators removed |
| `net_amount` | table | `Decimal` | a plain decimal string, the layout's separators removed |
