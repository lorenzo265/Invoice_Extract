# Samples

Fictional data only — no real company, invoice, or VAT number appears here.
`docs/SAMPLES_SPEC.md` has the exact page content and golden values these two files
encode.

Both PDFs are generated by `scripts/make_samples.py` (PyMuPDF). **Never edit a PDF, or
an `expected.json`, by hand** — regenerate instead:

    python scripts/make_samples.py

Fixed coordinates, a fixed font, and fixed metadata keep the output byte-identical run
to run. `tests/integration/test_samples_deterministic.py` runs the script twice and
compares SHA-256 hashes of both PDFs to enforce it.
